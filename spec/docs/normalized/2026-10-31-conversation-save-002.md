## Key claims

1. **Third parties (revises R9 and R17):** the restriction is on *paid* third-party services, on *structural* services (CMS, databases), and on anything that *tracks user data*. 2. **Performance:** no numeric target. Keep transfer as low as possible and cache as much as possible, because travellers navigate on e-SIM.

4. **Itinerary:** the user will supply a JSON file, after the first stages of the project are running, that defines calendar dates and the location for each date. The system must rearrange the dashboard according to the date, using Japan time (not Rome time).
5. **Aesthetics:** the shadcn style is not yet chosen. The look must be easy to change later, so the visual system should be modifiable from one place.
